# Manchester-City-Council-Expenditure

This data analysis project explores changes in Manchester City Council’s spending patterns.

I conducted comparative analysis and created visualisations (Power BI), which highlighted how priorities and fund distribution evolved despite overall stable expenditure levels.

The analysis focused on shifts from Q4 2024 to Q1 2025 in total expenditure, service areas, suppliers, and transaction types, identifying key changes such as a significant drop in Adult Social Care spending and shifts in housing- and construction-related payments.
